# User Flows

- FigJam / Figma link: (ใส่ลิงก์ที่นี่)

## Customer (no login)
Scan table QR -> Browse menu -> Add to cart (+ note) -> Checkout (order type, table, name, special request) -> Payment method -> Confirm & pay -> Live tracking (Placed -> Preparing -> Ready -> Served)

## Staff / Admin (login)
Login -> Dashboard -> Invoice (Payment / Cancel) | Menu | Stocks | Employees | Reports
