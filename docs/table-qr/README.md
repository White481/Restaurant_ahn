# QR ประจำโต๊ะ

- [`table-qr.pdf`](table-qr.pdf): การ์ด 5 โต๊ะบน A4 แผ่นเดียว พิมพ์แล้วตัดตามเส้นประ (การ์ดละประมาณ 9 × 9 ซม.)
- `table-1.png` … `table-5.png`: QR อย่างเดียว ความละเอียด 1000 px

แต่ละ QR ชี้ไปที่ `https://restaurant-ahn.vercel.app/?table=<เลขโต๊ะ>` (เลข = `dining_table.table_id`)
ลูกค้าสั่งได้เมื่อพนักงานกด "เปิดโต๊ะ" ในหน้า **พนักงาน → โต๊ะ** แล้ว
